# 📚 Smart Study Planner

Smart Study Planner is a frontend-only web application that helps students manage their subjects, tasks, and study schedules efficiently. The app uses browser LocalStorage to save data and includes a dark mode for better usability.

---

## ✨ Features

- 📊 Dashboard overview
- 📘 Subject management with priority levels
- 🗓️ Study schedule planner with time conflict detection
- ✅ Task manager with due dates
- 📈 Progress analytics
- 🌙 Light / Dark mode
- 💾 LocalStorage-based data persistence
- 📦 Export and reset data options

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- Browser LocalStorage

## 🚀 How to Run

1. Download or clone the project
2. Open `index.html` in any web browser
3. Start using the planner

No installation or backend required.

---

## 🌙 Dark Mode

Toggle dark mode from the **Settings** section.  
The selected theme is saved automatically.

---

## 💾 Data Storage

- Data is stored in the browser using LocalStorage
- Data persists after page refresh
- Use **Reset Data** to clear all saved information

---

## 📦 Export Data

Export all subjects, tasks, and schedules in JSON format for backup or debugging.
